# Mario Forever Galaxy – Android project
Game lives in www/index.html (touch UI: left joystick, FIRE / BOMB / AUTO / pause).

## Easiest: build online (no installs)
1. Create a free GitHub repo and upload all these files (keep the .github folder).
2. Open the Actions tab > "Build APK" > Run workflow.
3. Download the MarioForeverGalaxy-APK artifact, unzip, install app-debug.apk on your phone
   (allow "install unknown apps").

## Build on your own computer
Install Node 18+, JDK 17, Android Studio (SDK), then run ./build.sh
